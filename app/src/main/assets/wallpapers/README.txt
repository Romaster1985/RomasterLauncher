Place wallpaper images (PNG / JPG / WEBP / BMP) in this folder.

They appear automatically in the wallpaper picker — no code changes needed.

Optional: create subfolders for categories, e.g.:
  wallpapers/Nature/forest.jpg
  wallpapers/Nature/lake.png
  wallpapers/Cyberpunk/neon.webp

Subfolders show as a collage thumbnail with the folder name; tap to open.

Preferred first-install default filename: default.png (or .jpg / .webp)
